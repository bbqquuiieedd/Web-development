# Изучение Web

Здесь находится материал из моих практик в Sololearn по изучению Веб-разработки
Пустые страницы - это скорее всего страницы с работой над логами консоли (нажми F12 в браузере)

## Список дел

- Добавить кнопку "?" для контактной информации (добавить ссылку на GitHub)
- Убрать кнопку поднятия наверх страницы на мобильных устройствах (которая добавляется браузером поверх нашей)
- Добавить маркеры для HTML, CSS и JS
- Сделать шапку с названием слева и строкой поиска справа или по центру и кнопкой изменения темы (в качестве шаблона Sololearn), практики размещаются по центру, небольшой градиент цветов по центру, скроллбар свой, кнопку поднятия наверх страницы вернуть
- Поменять задний фон на более нежные цвета (вернуть изменение темы?)
- Поменять полосу прокрутки

## Список идей

- Возможность скрыть модуль (запоминать выбор) (при поиске будет разворачиваться)
- Запрет на выделение текста?
- Добавить звёздочки для обозначения сложности работ
- Пересмотреть материал, оставить самые интересные работы, а также сделать различные интересные проекты где будет сборная солянка из всего материала
