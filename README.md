# Изучение Web

Здесь находится материал из моих практик в Sololearn по изучению Веб-разработки
Пустые страницы - это скорее всего страницы с работой над логами консоли (нажми F12 в браузере)

## Список дел:

- Переделать кнопку переключения темы (сделать её в верхнем правом углу и сделать анимацию более приятной, например как в ТГ, также поменять эмодзи для обозначения темы)
- Сделать более круглую иконку для страницы
- Разбить скрипты и стили по разным файлам (один файл разбить на несколько файлов, соответствующих задаче)

## Список идей

- Сделать, что бы кнопка прокрутки плавно увеличивалась при наведении 
- Сделать выпадающее меню (модули видно всегда, а подпункты при нажатии)
- Сделать красивые анимации появления списка (При загрузке страницы модули появляются по очереди с лёгким сдвигом вверх)
- Сделать реакцию на любое действие (увеличивание слова при наведении?, при перетаскивании? Запрет на выделение текста?)
- Сделать шапку страницы для всех файлов (Название, переключение темы, цитата дня?)
- В каждом материале в верху страницы отображать путь по навигации страницы
- Сделать цитату дня
- Добавить звёздочки для обозначения сложности работы
- Добавить комментарии к материалам из практик
- Добавить материал из учебников по HTML и моих работ по УФИС
- Пересмотреть материал, оставить самые интересные работы, а также сделать различные интересные проекты где будет сборная солянка из всего материала
